# TravelSplit — generated visual concepts

Двадцать четыре визуальных направления, созданных по содержанию корневого `README.md` и приложенным стилевым референсам.

## Файлы

- `backgrounds/background-alpine-calm.png` — спокойный живописный горный фон с зоной низкой детализации под интерфейс.
- `backgrounds/background-coastal-road.png` — реалистичный прибрежный маршрут с большим количеством свободного пространства.
- `backgrounds/background-forest-tent.png` — лесной лагерь с палаткой и мягким утренним светом.
- `backgrounds/background-ocean-cape.png` — туманный мыс над океаном с тропой как визуальным маршрутом.
- `backgrounds/background-night-campfire.png` — тёмный фон с костром, лесом и ночным небом для dark mode.
- `backgrounds/background-city-arrival.png` — спокойный городской сюжет прибытия после дождя.
- `backgrounds/background-highland-road.png` — дорога вдоль холодного озера в пасмурной долине.
- `backgrounds/camp-cycle/` — одна сцена с палаткой в четырёх состояниях: утро, день, вечер и ночь.
- `interfaces/interface-desktop-dashboard.png` — desktop-концепт, объединяющий маршрут, карту, расходы, долги, билеты, чек-лист и фото.
- `interfaces/interface-desktop-home-simplified.png` — упрощённый начальный экран с блоками «Сегодня», «Маршрут» и «Баланс группы».
- `interfaces/interface-mobile-trip-overview.png` — mobile-концепт обзора групповой поездки.
- `interfaces/interface-mobile-home-simplified.png` — упрощённый mobile-экран с расписанием, балансом и ближайшим бронированием.
- `interfaces/daily-journey/` — цельный сценарий «пространства поездок»: вход, дневная, закатная и ночная темы, создание новой поездки.
- `interfaces/daily-journey/camp-cycle/` — текущий интерфейс на фоне лагеря во всех четырёх состояниях суток.

## Визуальное направление

- Палитра: туманно-голубой, сланцевый, шалфейный, молочный, глубокий хвойный, светлый каменный.
- Характер: спокойный, взрослый, практичный, без неона и чрезмерного glassmorphism.
- Образ: путешествие как организованный общий опыт, а не туристическая реклама.
- Референсы использованы только для настроения, фактуры мазка, глубины и горной атмосферы; композиции созданы заново.

## Генерация

Изображения созданы встроенным инструментом `image_gen`. Полные производственные промпты находятся в `PROMPTS.md` и `interfaces/daily-journey/PROMPTS.md`.

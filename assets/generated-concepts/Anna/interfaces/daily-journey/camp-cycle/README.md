# TravelSplit — Camp day cycle

Четыре состояния одного интерфейса и одной фоновой сцены.

## Экраны

- `01-morning.png` — низкое утреннее солнце, лучи через лес, палатка без света, костровище потушено.
- `02-day.png` — яркий дневной свет, солнце в верхней точке дуги, палатка и костровище без света.
- `03-evening.png` — тёплый закат, внутри палатки появляется мягкий свет, костровище остаётся потушенным.
- `04-night.png` — луна и звёзды, тёмные карточки, свет в палатке и небольшой горящий костёр.

Соответствующие чистые фоны находятся в `../../../backgrounds/camp-cycle/`.

## Инварианты

- Положение гор, деревьев, палатки, тропы и костровища не меняется.
- Компоненты интерфейса, размеры карточек и контент остаются на месте.
- Палатка остаётся заметна: интерфейс занимает левую и центральную часть экрана.
- Солнце перемещается слева направо по дуге; в ночном состоянии его заменяет луна.
- Костёр горит только ночью.
